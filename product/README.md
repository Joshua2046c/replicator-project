# 三件式收纳座钟

按两张参考图制作黄色、无刻度圆盘座钟，结构分成顶部可收纳的底座、方榫连接的加厚钟主体，以及被钟主体包住的嵌套盘面。指针扫掠范围纯平，外缘平滑翘起。

指针长度按用户原文记录为 14 mm，待核对量纲后确定圆盘及整体比例。默认 FDM 塑料制作，三个结构件分别制造。

不使用开发板或自定义 PCB，使用独立电池式通用石英钟芯。初步空间依据为 56 × 56 × 16–17 mm 类别：https://www.m-p.co.uk/muk/parts/movements-quartz.htm 。机械选型阶段落实安装接口。

验收：三个主要结构件；顶部收纳口可用；方榫可装配；盘面嵌套无穿插；钟芯可装入及更换电池；交付装配 STEP。
