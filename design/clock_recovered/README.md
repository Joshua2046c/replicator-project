# STEP恢复座钟

## Must satisfy
本设计是clock的交付替代设计，恢复基准为recovery_step：最后完整导出的STEP（SHA256 5ace57df0fda9a15847270cbe66048984c366595415927b0751c0765d7b14559）。六个制造件：收纳底座base、钟壳body、一体表盘dial、磁吸电池盖battery_cover、左右独立粘合滑轨rail_left/rail_right。原设计保留作历史参考，不与恢复设计同时装配。

从STEP直接提取六个解析实体，使用压缩BREP拓扑作为各零件的固定原始几何，保存在受管理的源单元中；大数据单元只保存恢复几何，features单元完整描述后续特征。每个数据载荷均带SHA256断言；不将圆面转换为网格。STEP没有原始建模历史，恢复件支持直接增删特征；已开放磁铁孔的共享直径、深度、中心位置，以及各独立件的展示定位参数。

battery_hatch：后盖与钟壳上缘中央对应的一对磁铁孔统一为Ø7.1×深1.1 mm，中心X=0、Y=23 mm。钟壳孔口Z=2.5、孔底Z=3.6 mm；盖孔口Z=2.2、孔底Z=1.1 mm。实体孔底名义留料分别2.0 mm、1.1 mm。58×58 mm、R3磁吸盖及下缘15×2 mm长方形扣手保留；背板5.6 mm，磁铁座内侧与背板内面齐平。机芯腔净深20.4 mm，用户最低要求17 mm。

dial_nest：原图数字和60个刻度与盘面保持一个连续实体，凸起0.6 mm。四对盘面磁铁孔维持Ø7.1×深1.1 mm、半径111 mm。盘面及钟壳位置保留恢复STEP中的位置；盘面支撑环连续到底。

slide_mount：两根独立粘合T形轨保持原结构，背面定位浅槽0.1 mm，胶床0.05 mm；入座滑动面原名义单侧0.25 mm，最低0.1 mm，顶面入座齐平。底座宽90 mm、高160 mm，底座槽外侧及下圆角原要求至少2 mm，连接颈端直角保留。底座在盘面旁边保持竖直、底面Z=0。

wall_hanger：背部上方居中钥匙孔及内侧16×26 mm R3、深2.8 mm凹位保持STEP原样。

## Making and assembly
默认黄色PETG/FDM。盘面为单体，原图1–12数字及12宽小时条、48条分钟细线保留；白色通过浮雕表面涂装或切片器表面分色实现。指针下表面目标距平盘面至少1.1 mm，实物机芯和指针仍需试配。钟芯参考56×56×17 mm类别、总轴长14 mm，使用原配轴螺母与垫圈；最长指针90 mm。未用占位实体代替机芯。

底座底面向下；伸颈悬垂处由切片器设置支撑，保护滑动面和直角端部。盘面背面向下，整径234 mm，核对打印机幅面。钟壳背面向下打印时保护R7后缘、磁铁盲孔及0.1 mm浅定位槽，定位面宜使用不超过0.1 mm层高或朝上打印，防止象脚吞掉定位浅槽。环形承托下方为实料；挂孔凹位底部剩余2.8 mm。

盖子外平面向下、磁铁孔向上；壳体和盖子每孔放一颗Ø7×1 mm磁铁，名义单侧胶隙0.05 mm、轴向余量0.1 mm。孔底保留材料，粘前先试装并检查相吸极性。盘面另需8颗相同磁铁，共10颗，等级和磁吸力未实测。按PETG与磁铁材质选择胶水，勿堵住盖周0.3 mm间隙。盖子安装后，两孔口之间保持原0.3 mm间隙。

左右轨粘接面朝下打印，保护下端R2与斜切上端；先做短滑轨试配校准收缩。清理定位浅槽和毛刺，先干装试滑确认顶部齐平，再按胶种要求粘合固化，两轨必须保留分体。日常换电池先从底座向上滑出钟体，再从盖下缘矩形缺口扣开后盖。挂墙时取下底座，钉帽应能进入Ø9入口且大于3.8 mm窄颈，墙面和钉子承载由实物确认。

## Inspection
最终六件均为有效单一封闭实体；表壳与后盖的目标孔逐一实测Ø7.1×深1.1 mm。盖壳间隙实测0.3 mm。改孔后使用SkipClean保持原外圈解析曲面细分，钟壳902面、盘面2331面，避免清理布尔运算时将原细分曲面并为粗分段预览。初次精确体积核验显示表壳及盖子仅增加预期的约8.608416 mm³孔底/孔壁材料；其余四件恢复实体的几何保持一致。未进行实物打印、磁吸力、胶合承载或整机稳定性试验。

## Open
Ø7×1 mm磁铁为用户尺寸，等级未指定。机芯14 mm为总轴长，螺纹与指针压装接口仍需实物确认。
