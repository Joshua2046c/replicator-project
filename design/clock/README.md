# 三件式收纳座钟

## Must satisfy
三个结构件：base、body、dial。方榫 tenon；盘面嵌套 dial_nest；钟芯安装 movement。用户轴长14 mm、指针最大90 mm；图片的102 mm分针通过直径216 mm平区兼容。依照新参考图，盘面后仰8°，钟体外径240 mm、厚32 mm，后缘7 mm倒角、前缘1 mm倒角，背板厚3.5 mm且完全封闭。底座84×90×160 mm、外角R18；整机高291.15 mm，钟体下缘离桌面50.14 mm，收纳口接近指针轴心高度。黄色PETG。8°为参考照片的设计估计值。通用钟芯无需控制板及外部接线；外壳依据 https://www.m-p.co.uk/muk/parts/movements-quartz.htm 的56×56×17 mm类别，不采购12 mm轴型号。

## Making and assembly
底座底面朝下打印；壁厚3 mm、底厚6 mm，口沿与底边R0.8。盘面背面朝下，中心厚2.4 mm、边缘升高3 mm；直径234 mm，打印机需足够幅面。钟体可正面朝下打印，凹部和背部支承需要支撑；支撑不要伤及盘面台阶及封闭背板。倾角改变后先在切片器检查朝向及支撑。先试配再修整。方榫20 mm、孔20.5 mm、插入25 mm，底部留0.5 mm余隙；滑配可用少量可移除胶固定。顶部支承宽72 mm、高8 mm、R3，方榫保持竖直。
先将钟芯轴穿过盘面，使用随钟芯提供的垫圈螺母，再把盘面和钟芯一起装入钟体；台阶贴0.2 mm可移除胶点，不用整圈永久胶。盘面与前口单边径向间隙0.3 mm；轴向台阶间隙0.2 mm。换电池时托住底座，先拔下钟体并平放，借助小吸盘从正面轻轻取下盘面与钟芯，再更换电池和胶点，避免拉扯指针。背面不再设检修孔。方榫不是承重提手，搬动时托住底座。尚未实物打印，公差需试装。

## Inspection
已检查正斜视、背面、侧面及隐藏盘面后的内部。三个有效独立实体，三个零件对均无体积交叠。盘面为平面，法向对应8°后仰；中心保留64×64×22.5 mm安装净空间，较56×56×17 mm参考钟芯留有余量。机芯本体不建替代实体。

## Open
钟芯总轴长14 mm已确认，但螺纹长度和指针安装孔未量测；中央10 mm孔按现有供应商参考预留。外购钟芯和指针未生成代用实体，STEP只含三个结构件。修改body_tilt_angle时需同步盘面的装配旋转及轴向位置，以保持嵌套；底座与方榫仍保持竖直。
