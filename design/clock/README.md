# 三件式收纳座钟

## Must satisfy
三个结构件：base、body、dial。方榫 tenon；盘面嵌套 dial_nest；钟芯安装 movement。用户轴长14 mm、指针最大90 mm；图片的102 mm分针通过直径216 mm平区兼容。按最新标注图增加后仰并隐藏方形连接桩：盘面后仰16°，钟体外径240 mm、厚32 mm，后缘7 mm倒角、前缘1 mm倒角，背板厚3.5 mm且完全封闭。底座落地84×90 mm、高160 mm，前肩最大深度98.61 mm、外角R18；前上部30 mm高斜面与钟体背面贴合。整机高291.90 mm，钟体下缘离桌面54.58 mm。黄色PETG。16°为本轮设计默认值。通用钟芯无需控制板及外部接线；外壳依据 https://www.m-p.co.uk/muk/parts/movements-quartz.htm 的56×56×17 mm类别，不采购12 mm轴型号。

## Making and assembly
底座底面朝下打印；壁厚3 mm、底厚6 mm，口沿R0.8；本轮底部采用平面直接落地，前肩平滑过渡到贴合面。榫根凹槽沿顶部敞开，收纳腔仍独立。盘面背面朝下，中心厚2.4 mm、边缘升高3 mm；直径234 mm，打印机需足够幅面。钟体可正面朝下打印，凹部和背部支承需要支撑；支撑不要伤及盘面台阶及封闭背板。倾角改变后先在切片器检查朝向及支撑。先试配再修整。方榫20 mm、孔20.5 mm、插入25 mm，底部留0.5 mm余隙；滑配可用少量可移除胶固定。方榫保持竖直，榫根宽20 mm、高15 mm，全部位于底座口沿以下，顶部与口沿齐平。贴合面为名义接触面；先修整打印毛刺，再竖直插入，勿用力楔紧。
先将钟芯轴穿过盘面，使用随钟芯提供的垫圈螺母，再把盘面和钟芯一起装入钟体；台阶贴0.2 mm可移除胶点，不用整圈永久胶。盘面与前口单边径向间隙0.3 mm；轴向台阶间隙0.2 mm。换电池时托住底座，先拔下钟体并平放，借助小吸盘从正面轻轻取下盘面与钟芯，再更换电池和胶点，避免拉扯指针。背面不再设检修孔。方榫不是承重提手，搬动时托住底座。尚未实物打印，公差需试装。

## Inspection
已检查侧面、正斜视和背面。三个有效独立实体，三个零件对均无体积交叠；底座/钟体最小距离0 mm，贴合接触；钟体/盘面最小间隙0.2 mm。外露横台已取消。盘面法向对应16°后仰；中心保留64×64×22.5 mm安装净空间，较56×56×17 mm参考钟芯留有余量。机芯本体不建替代实体。

## Open
钟芯总轴长14 mm已确认，但螺纹长度和指针安装孔未量测；中央10 mm孔按现有供应商参考预留。外购钟芯和指针未生成代用实体，STEP只含三个结构件。改变倾角时同时同步body_tilt_angle、base_contact_angle、底座榫槽前后位置以及钟体和盘面放置。钟体背中心Y=-10+8*tan(angle)，Z=168；底座榫槽本地Y=18+8*tan(angle)。盘面背中心由钟体背中心沿朝前法向移动26 mm，盘面装配旋转X=90-angle。榫与槽仍竖直。
