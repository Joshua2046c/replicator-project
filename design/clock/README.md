# 伸颈式收纳座钟

## Must satisfy
三个主要结构件 base、body、dial，加独立小方定位块 locator，共四个制造件。用户要求缩小方桩并与钟体分体，以浅凹孔定位粘合；底座前上部采用伸脖子造型，下方圆滑内凹。盘面后仰16°；钟体直径240 mm、厚32 mm、后倒角7 mm、前倒角1 mm。底座高160 mm、宽84 mm，落地前后约92 mm，总包络深103.15 mm；后侧底部内收8 mm，侧边R18。整机高291.90 mm，钟体下缘离桌面54.58 mm。
用户轴长14 mm、最长针90 mm；直径216 mm平区兼容参考图片另标102 mm分针。机芯完全隐藏，壳体背板3.5 mm，浅槽底剩2.3 mm，不开后检修孔。内部预留64×64×22.5 mm；参考 https://www.m-p.co.uk/muk/parts/movements-quartz.htm 的56×56×17 mm类别，不采购12 mm轴型号。材料默认黄色PETG，无控制板及外部接线。

## Making and assembly
底座底面朝下打印，侧后壁名义3 mm、底厚6 mm，口沿R0.8，侧边R18。前伸脖子下方有悬垂，切片时从底板添加支撑，保护胶合定位面，去支撑后修整毛刺。收纳腔与胶合凹槽分开。
钟体与小方块分别打印；钟体可调整为背面朝下，让盘面台阶向上，浅凹槽处检查桥接；如正面朝下，则对内部凹处采用支撑并保护嵌套台阶。小方块以12×12 mm大面落地，厚5 mm，棱边倒角0.2 mm。盘面背面朝下，中心厚2.4 mm、边缘升高3 mm；直径234 mm，打印机需足够幅面。先试配再修整，尚未实物打印。
独立定位块12×12×5 mm，钟体槽12.5×12.5×1.2 mm，底座槽12.5×12.5×4.2 mm。装配后进入钟体1 mm、底座4 mm；两端各有0.2 mm胶层空间、单边侧隙0.25 mm。先干装检查，再用用户选定且适合打印材料的胶粘合；保持16°贴合角并支撑钟体直到固化。胶种、表面处理和实际承载强度需实物试验；方块主要用于定位，不把它当作可拔插榫头。搬动始终托住底座。
先完成底座与钟体胶合，再将机芯轴穿过盘面，使用原配垫圈螺母安装。盘面连同机芯从正面放入钟体，台阶贴0.2 mm可移除胶点，不用整圈永久胶。盘面与前口单边径向间隙0.3 mm、轴向台阶间隙0.2 mm。
换电池时保持底座与钟体粘合，支撑整机并使盘面朝上，借助小吸盘轻轻取出盘面与机芯，换电池并更换胶点后复装；避免拉扯指针。不再尝试拔下钟体。

## Inspection
已检查装配侧面及正斜视、独立底座的收纳口与伸颈轮廓、钟体背面浅槽细节。四个有效实体，六对零件均无体积交叠；底座/钟体名义接触，定位块/底座和定位块/钟体最小间隙均0.2 mm，钟体/盘面最小间隙0.2 mm。浅槽位于封闭背板外侧，机芯安装腔不受影响。未进行胶合承载或实物打印试验。

## Open
14 mm为钟芯总轴长，螺纹长度和针孔需实物量测；10 mm轴孔沿用供应商参考。机芯和指针不建代用实体；STEP含四个制造件。
参数同步：body_tilt_angle与base_contact_angle一致；钟体背中心Y=-10+8*tan(angle)，Z=168。浅槽中心在钟体未旋转框架Y=-24；base_locator_drop=24*cos(angle)-8；底座槽本地中心为(0,-drop*tan(angle),160-drop)。定位块中心从钟体槽口沿朝前法向后退1.5 mm，旋转X=90-angle；盘面背面从钟体背中心沿朝前法向前进26 mm，旋转X=90-angle。修改角度或定位位置须同步这些放置参数。
