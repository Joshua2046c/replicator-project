# 三件式收纳座钟

## Must satisfy
三个结构件：base、body、dial。方榫 tenon；盘面嵌套 dial_nest；钟芯安装 movement。用户轴长14 mm，指针最大90 mm；图片的102 mm分针通过直径216 mm平区兼容。外径240 mm，整机高340 mm，黄色PETG。通用钟芯不是索引平台板，无外部接线。参考尺寸来源 https://www.m-p.co.uk/muk/parts/movements-quartz.htm ，仅用56×56×17 mm外壳类别，不采购12 mm轴型号。

## Making and assembly
底座底面朝下打印；壁厚4 mm、底厚6 mm。盘面背面朝下，中心厚2.4 mm，边缘升高3 mm；直径约234 mm，打印机需足够幅面。钟体正面朝下时须在凹部使用支撑，避免支撑损伤盘面台阶；先试配再修整。方榫20 mm、孔20.5 mm、插入25 mm，底部留0.5 mm余隙，滑配可用少量可移除胶固定。先将钟芯轴穿过盘面，使用随钟芯提供的垫圈螺母，再把盘面压入定位台阶；台阶上贴0.2 mm可移除胶点。由后部64 mm方孔维护电池，必要时先取下钟体。方榫不是承重提手，搬动时托住底座。尚未实物打印，公差需试装。

## Open
钟芯总轴长14 mm已确认，但螺纹长度和指针安装孔未量测；中央10 mm孔按现有供应商参考预留。外购钟芯和指针未生成代用实体，STEP只含三个结构件。
